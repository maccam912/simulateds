# Third-party code

This project starts from the MIT-licensed
[maccam912/godot-iroh-template](https://github.com/maccam912/godot-iroh-template),
revision `2e95d762c421600fd287da92269669361204309e`. Its native transport, room
discovery, Android integration, pinned toolchain, build helpers, and export/CI
infrastructure are retained. Simulateds replaces the demo with its own world,
protocol, persistence, presentation, tests, and documentation. Its ALPN and room
namespace are `simulateds/1`.

The Rust transport in `native/iroh/src` derives from
[Tipragot/godot-iroh](https://github.com/Tipragot/godot-iroh), upstream revision
`153979fc02f86b10802358ae38fb74204fbf179a`, via the user's Pacific Rush/racinggame
integration. Its MIT license is retained in `licenses/godot-iroh-MIT.txt`.
Inherited transport changes include Iroh 1.4.1, full address tickets, bounded
client polling, connection deadlines, explicit disconnection checks, corrected
negative-peer exclusion, a seven-client cap, and a renamed Android JNI bridge.

No racing gameplay, tracks, cars, game art, or private service credentials are
included. The code service is an external dependency configured by URL.

Godot is MIT-licensed. `licenses/godot-LICENSE.txt` and
`licenses/godot-COPYRIGHT.txt` contain the engine's notices for the pinned release.
The Godot engine also exposes third-party license information through its APIs.

Rust package versions and declared license expressions are locked by Cargo.lock.
`licenses/rust-dependencies.txt` is generated by `python3 tools/licenses.py` and
collects package notices from the resolved sources, including build-only and
target-specific crates. It is deliberately a superset of the packages linked into
any one platform. Review this file after upgrading dependencies and preserve it
when distributing compiled games. The template's export presets include notices.

## Original 3D art

The Linden Grove mesh library under `assets/models/` is original project content
created from the retained Blender generator `tools/generate_models.py`. It uses
procedural geometry and palette materials, with no third-party mesh or texture
downloads. Model metadata and the reproducible workflow are documented in
[docs/ASSET_GUIDE.md](docs/ASSET_GUIDE.md). Blender is an authoring dependency;
its executable is not distributed with the game.
